# SysADV v0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar consumo DataJud observável, manutenção completa de processos, menus funcionais e consulta DataJud forçada no SysADV.

**Architecture:** Manter monorepo React/Fastify/Prisma. Persistir chamadas externas em `IntegrationRequest`, usar soft delete para processos e separar rotas/serviços de auditoria, integrações, dashboard e cálculos.

**Tech Stack:** React 18, TypeScript, Fastify, Prisma, PostgreSQL 16, Vitest, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-17-sysadv-v0.3.0-design.md`

## Global Constraints

- Não persistir nem retornar `DATAJUD_API_KEY` ou headers de autorização.
- Campos VALIDATED não podem ser sobrescritos por consulta DataJud.
- Exclusão de processo é lógica, nunca física.
- Cálculos não devem simular execução do PJe-Calc.
- Todos os novos imports ESM relativos devem usar extensão `.js`.
- Preservar segregação por `organizationId` em todas as consultas.
