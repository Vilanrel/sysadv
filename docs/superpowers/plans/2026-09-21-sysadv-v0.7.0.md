# SysADV v0.7.0 PJe-Calc Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrar o ciclo de preparação, versionamento, intercâmbio e rastreabilidade do PJe-Calc ao SysADV e adicionar a marca d'água da Justiça no login.

**Architecture:** Expandir o domínio Calculation com versões, artefatos, pacotes e execuções PJe-Calc; manter o intercâmbio manual como modo seguro e criar contrato para agente local opcional. O frontend passa a oferecer workspace de cálculo e a API expõe operações de validação, pacote, importação e execução sem afirmar uma API remota inexistente do PJe-Calc.

**Tech Stack:** TypeScript, Fastify, React, Prisma/PostgreSQL, Vitest, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-21-sysadv-v0.7.0-pjecalc-design.md`

## Global Constraints
- Versão final: `0.7.0` em API, frontend e scripts.
- Preservar dados e compatibilidade da v0.6.0.
- Não simular API remota do PJe-Calc; modo manual `.PJC` e agente local opcional.
- Segredos não entram no pacote de distribuição.
- Cálculo exige validação profissional antes de ser marcado como pronto para PJe-Calc.
- Login recebe marca d'água vetorial da Justiça com baixa opacidade e sem reduzir acessibilidade.

## Review Focus
- Pacote solicitado antes de validação profissional deve ser rejeitado.
- Importação deve rejeitar arquivo sem extensão `.pjc` ou payload vazio.
- Agente não configurado deve produzir estado/erro explícito, não sucesso fictício.
- Comparação de versões deve manter histórico imutável.
- Marca d'água não deve interceptar foco/cliques nem virar conteúdo acessível redundante.
