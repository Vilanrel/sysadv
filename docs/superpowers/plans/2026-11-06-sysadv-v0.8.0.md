# SysADV v0.8.0 Implementation Plan

> For agentic workers: use superpowers:executing-plans, testing changes RED -> GREEN.

**Goal:** Introduzir modelos juridicos, armazenamento hibrido consistente, novos indicadores e UI responsiva.

**Architecture:** Fastify/Prisma para metadados e RBAC; volumes Docker para blobs e cache; React/Vite para editor/preview. Sem chamadas externas ao Projuris.

**Tech Stack:** TypeScript, Node 22, Fastify, Prisma 6, PostgreSQL 16, React 19, Docker Compose.

**Spec:** docs/superpowers/specs/2026-11-06-sysadv-v0.8.0-design.md

## Global Constraints
- Isolar toda consulta por organizationId, inclusive processId e modelId.
- Nao apagar volumes e respeitar documentos originais de v0.7.
- Nao copiar modelos juridicos Projuris.
- Usar apenas APIs oficiais com permissoes.

## Review Focus
- Variaveis ausentes e payload malicioso devem ser tratados sem injecao.
- ID de processo de outra organizacao deve falhar.
- Import DOCX malformado e acima de 5MB deve ser rejeitado.
- Cache corrompido ou expirado nunca deve devolver dados de outra organizacao.
- Atualizacao com dados antigos e arquivos originais deve preservar acessos.
