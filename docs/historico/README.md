# Historico SysADV

Arquivos antigos de releases, hotfixes e verificadores foram deslocados para esta area para evitar execucao acidental na release corrente.
Os scripts aqui sao **historicos** e nao devem ser usados para publicar a versao atual.
O codigo ativo permanece em `apps/`, `packages/`, `prisma/`, `scripts/` e `tests/`.
