# SysADV — Estudos de direção visual (Image Generator)

O usuário pediu modernização do SysADV com **Image Generator**. Os dois arquivos PNG são **explorações conceituais**, não capturas autenticadas, e **não correspondem ao inventário funcional** da versão v0.9.2. Alguns cartões incluem dados fictícios e módulos ainda não confirmados na aplicação. Não devem ser publicados como divulgação de funcionalidades prontas, nem integrados às telas de operação.

- `sysadv-conceito-telas-responsivas-01.png`: composição conceitual de telas de software jurídico em notebook, tablet e celular, paleta azul-marinho e violeta. Texto alternativo: "Estudo conceitual de painéis jurídicos em desktop, tablet e celular, com tabelas e gráficos roxos."
- `sysadv-conceito-telas-responsivas-02.png`: composição conceitual de navegação, dashboards, calendários e cartões em diferentes dispositivos. Texto alternativo: "Estudo de telas responsivas de software jurídico com menu lateral e painéis claros sobre fundo azul."

**Decisão de implementação:** manter os elementos de trabalho como HTML e CSS reais, com a identidade corporativa original. Não converter uma imagem de mockup em um aplicativo nem inserir nela números, pessoas e funcionalidades ficcionais.

As capturas `../qa/layout-estatico-*.png` são **evidências de um fixture HTML** ligado ao stylesheet real; não são execuções autenticadas do produto.
